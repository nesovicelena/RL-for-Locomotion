# Experiment log

One entry per run that taught you something — including the failures, which are
usually the ones worth writing down. Keep it chronological and short.

The point is that in six months you can answer "did I already try that?"
without re-reading every W&B dashboard.

---

## Template

### YYYY-MM-DD — <run name>

- **Config:** `configs/experiment/<file>.yaml`
- **Run dir:** `experiments/runs/<exp>/<timestamp>_<sha>/`
- **W&B:** <link>
- **Question:** what were you actually testing?
- **Result:** what happened, with numbers.
- **Conclusion:** what you changed as a consequence.
